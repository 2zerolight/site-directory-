취업 준비를 시작하면 사이트를 열 개쯤 열어두게 됩니다. 그런데 대부분은 같은 공고를
보여주고, 정작 필요한 기능은 다른 곳에 있습니다. 종류가 아니라 **과정의 어느 단계에서
쓰는지**로 나누면 정리가 됩니다.

## 1단계. 공고 찾기

모든 직군을 다루는 종합 플랫폼이 출발점입니다.

| 사이트 | 하는 일 |
|---|---|
| 사람인 | 채용 공고 검색, 이력서 등록·지원 |
| 잡코리아 | 채용 공고 검색, 이력서 등록·지원 |
| 인크루트 | 채용 공고 검색, 이력서 관리 |
| 커리어 | 채용 공고 제공, 이직 정보 제공 |

기능이 거의 같습니다. 공고가 완전히 겹치지는 않으니 두 곳 정도 등록해두고 알림을 받는
편이 낫습니다. 세 곳 이상은 같은 공고를 세 번 보게 됩니다.

**직군이 정해져 있다면 특화 플랫폼이 더 빠릅니다.**

- 원티드: IT·스타트업 채용 공고, 커리어 콘텐츠
- 로켓펀치: 스타트업 채용 정보, 네트워킹 지원
- 게임잡: 게임업계 채용 공고 제공
- 피플앤잡: 외국계 기업 채용 공고 제공
- 노트폴리오: 포트폴리오 공유, 디자인 채용 정보 제공
- 슈퍼루키: 신입 채용 정보 제공, 커리어 콘텐츠 제공

아르바이트는 아예 다른 시장입니다. 알바몬과 알바천국이 공고 검색과 지원을 다루고,
벼룩시장은 지역 일자리 매칭 쪽이 두텁습니다.

## 2단계. 회사 알아보기

**공고를 봤다면 지원 전에 회사를 조사하는 단계가 따로 있습니다.** 이걸 건너뛰면 면접에
가서야 알게 되는 것들이 생깁니다.

- 잡플래닛: 기업 리뷰 제공, 연봉 정보 제공
- 블라인드: 회사 리뷰 공유, 커리어 정보 교류
- 캐치: 채용 공고 제공, 기업정보 분석

잡플래닛은 리뷰와 연봉이 구조화돼 있고, 블라인드는 재직자 커뮤니티라 정제되지 않은
얘기가 오갑니다. 캐치는 공고와 기업 분석을 함께 봅니다. 성격이 달라서 한 곳만 보면
편향됩니다.

## 3단계. 지원서 준비

- 자소설닷컴: 채용 공고 제공, 자소서 첨삭
- 잡다: 역량검사, 채용 매칭
- 코멘토: 현직자 멘토링, 실무 프로젝트 제공
- 링커리어: 공모전 정보 제공, 인턴 정보 제공
- 커리어리: 커리어 콘텐츠 공유, 네트워킹

이력서에 쓸 게 없어서 막히는 단계라면 공고를 더 보는 것보다 링커리어나 코멘토 쪽이
직접적입니다. 채울 거리를 만드는 곳이기 때문입니다.

## 4단계. 경력직과 이직

신입 취업과 이직은 경로가 다릅니다. 경력직은 공고에 지원하는 것보다 **제안을 받는**
비중이 큽니다.

- 리멤버: 명함 관리, 이직 정보 제공
- 커리어케어: 경력직 채용 연결, 서치펌 서비스
- 유니코써치: 임원급 헤드헌팅, 전문 인력 매칭
- 탤런트뱅크: 전문가 프로젝트 매칭, 기업 컨설팅 연결

정규직이 아니라 일 단위로 움직인다면 크몽(프리랜서 서비스 거래)과 숨고(전문가 매칭,
견적 비교)가 그 시장입니다.

## 공공 서비스는 따로 있습니다

민간 플랫폼만 보다 보면 놓치는 축입니다. 교육과 지원금이 붙는 경우가 많습니다.

| 사이트 | 하는 일 |
|---|---|
| 고용24 | 채용 정보 제공, 직업훈련 신청 |
| 커리어넷 | 진로 심리검사, 직업 정보 제공 |
| 월드잡플러스 | 해외 취업 정보 제공, 해외 인턴십 지원 |
| 서울시50플러스 | 중장년 채용 정보 제공, 재교육 프로그램 운영 |
| 여성새로일하기센터 | 직업교육 제공, 취업 연계 지원 |
| 한국산업인력공단 | 자격시험 운영, 직업훈련 지원 |
| Q-Net | 자격시험 원서접수, 자격증 정보 제공 |
| K-Startup | 창업 지원사업 안내, 창업 정보 제공 |

취업 대신 창업을 보고 있다면 K-Startup, 자격증이 필요하면 Q-Net과 한국산업인력공단
쪽입니다. 근로 조건에 문제가 생겼을 때는 노동OK에서 노동법 상담과 노무 정보를 다룹니다.

## 정리하면

**1단계에 시간을 다 쓰지 마세요.** 공고를 찾는 일은 종합 플랫폼 두 곳으로 충분하고,
당락은 2단계와 3단계에서 갈립니다. 회사를 알아보지 않고 지원한 곳은 붙어도 오래 가지
않고, 쓸 거리가 없는 이력서는 공고를 아무리 많이 봐도 채워지지 않습니다.

> 각 사이트가 공식적으로 안내하는 대표 기능을 옮긴 것입니다. 채용 공고의 조건과 지원
> 절차는 사이트와 기업마다 다르므로 반드시 해당 공고에서 확인하세요.
